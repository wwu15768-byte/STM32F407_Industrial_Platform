## Current Milestone

- M1：STM32 裸机稳定基线。

## 本周核心目标

- 完成 M1 剩余的版本管理同步和目标板运行验证，建立真正可下载、可运行、可观测的 STM32F407VGT6 Known Good Baseline。

## 本周任务

- 补齐 CubeMX 工程和构建基线的 Git checkpoint、项目状态记录与远程功能分支备份。
- 使用 ST-LINK 下载当前裸机固件并完成 PB2 LED 最小心跳验证。
- 完成 USART2 PD5/PD6 调试输出和多次复位运行验证，判断 M1 是否达到最终验收标准。

## 验收标准

- `feature/m1-bare-metal-baseline` 已建立清晰的 CubeMX 工程和构建基线提交，并同步到远程。
- CMake + Ninja + GCC 构建能够稳定重复成功，构建产物不进入 Git。
- ST-LINK 能通过 SWD 识别 STM32F407VGT6、下载固件并复位运行。
- PB2 LED 按预期产生稳定心跳行为。
- USART2 通过 PD5/PD6 输出可观测调试信息。
- 多次复位后裸机基线能够重复正常启动。
- 对应测试、状态、日志和会话交接记录与实际工程状态一致。

## 风险

- PB2 同时是 BOOT1，需要保持正确启动条件并确认 LED 有效电平。
- USART2 使用 PD5/PD6，需要正确连接外部 3.3 V USB-TTL 并保证 TX/RX 交叉与共地。
- 当前“构建成功”尚不能证明实物运行成功，不能提前进入 FreeRTOS。
- Git 和项目文档必须在形成稳定 checkpoint 后及时同步，避免再次落后于实际代码进度。

## 可选任务
