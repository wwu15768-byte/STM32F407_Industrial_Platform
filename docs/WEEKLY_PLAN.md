# 周计划：2026-W37

> 唯一回答：这周准备干什么？
> 周期：2026-09-07 至 2026-09-13。每周更新一次。

## Current Milestone

M1：STM32 裸机稳定基线。

## 本周核心目标

生成、编译并下载一个硬件配置正确的最小 STM32 HAL 工程。

## 本周任务

1. 核对并记录开发板、MCU、时钟、LED、UART、SWD 和供电信息。
2. 使用 STM32CubeMX 生成 STM32F407VGT6 最小 HAL 工程并审查配置。
3. 建立 CMake + Ninja 构建流程，完成首次编译、下载和最小硬件验证。

## 验收标准

- CubeMX 器件明确为 STM32F407VGT6，时钟和引脚配置与硬件资料一致。
- CMake + Ninja 构建成功，并能识别编译、汇编、链接、objcopy 和 size 步骤。
- ST-LINK 能通过 SWD 识别目标、下载并复位运行。
- LED 与 USART2 调试输出按预期工作，测试证据已记录。

## 风险

- PB2 同时是 BOOT1，必须保持正确启动条件并让 LED 上电默认熄灭。
- 板载调试座引出的是 USART1，计划使用的 USART2 需要通过 PD5/PD6 外接 USB-TTL。
- 12 V 必须先转换为稳定 5 V，禁止直接接入开发板 5 V 输入。

## 可选任务

在首次构建时使用 Ninja 详细输出，辨认编译、汇编、链接和产物转换命令。
